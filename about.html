About Limn Engine

Limn Engine is a free, open, single-file 2D game engine for the browser — built from scratch by Owolabi Kehinde.

see more...

It started in 2023 as JGame — a tiny canvas wrapper written to avoid repeating the same game-loop boilerplate in every project. It grew into TCGame, then TCJSGame, and now Limn Engine (v4) — a complete architectural upgrade with a dual-canvas pipeline, a full particle system, scene management, circle collision, AnimatedSprite, and a proper audio system.

The goal has never changed: zero configuration, one file, maximum creativity. No npm. No webpack. No TypeScript compiler. Just an HTML file, epic.js, and your ideas.

Design Philosophy

Limn Engine is built around three principles.

see more...
  1. Zero friction. A new developer should have a moving square on screen in under 60 seconds. No setup, no CLI, no config files.
  2. Progressive depth. Level 1 teaches shapes and keys. Level 4 teaches dual-canvas pipelines and engine extension. The same engine serves both.
  3. Open code. Limn is plain JavaScript — no minification, no obfuscation. Read it, learn from it, patch it, extend it with Component.prototype.*.

The name Limn means to draw or portray — fitting for an engine whose job is to draw worlds.
