Extra CSS

                        

                        

                            Raw CSS injected as a <style> block in the head. Applies to the whole game page — you can style the body, add background layers, or reset defaults.

                            One URL per line. Each becomes a <script src="..."> tag in the head, loaded before the engine. Use this for libraries like Three.js, Matter.js, or your own CDN bundles.
