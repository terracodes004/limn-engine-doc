Head HTML

Raw HTML injected inside <head>. Use this for <link>, <meta>, or any custom tags. Works in preview, published games, and downloads.

💡 Paste tags exactly as you'd write them in an HTML <head>.
🎨

Extra CSS

Raw CSS injected as a <style> block in the head. Applies to the whole game page — you can style the body, add background layers, or reset defaults.

💡 Standard CSS. Runs after the engine's own styles so you can override them.
📜

External Scripts

One URL per line. Each becomes a <script src="..."> tag in the head, loaded before the engine. Use this for libraries like Three.js, Matter.js, or your own CDN bundles.

💡 Loads synchronously before the engine. If a script fails to load, the game will show an error in the console.
Changes apply on next Run or Save.
